# Markdown wiki quickstart

이 문서는 **Markdown 파일**에서 Confluence 페이지로 게시하는 시작 예제입니다.

## 사용 순서

1. 이 파일을 `wiki/` 폴더로 복사합니다.
2. `cfwiki upload`로 게시합니다.
3. 기록된 페이지 ID로 다운로드합니다.
4. 이 문장을 수정하고 다시 업로드합니다.
